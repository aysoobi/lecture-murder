# Lecture Murder: Смерть профессора

Детективная хоррор-игра в браузере. Профессор Мортон найден мёртвым в аудитории — у вас **4 минуты**, чтобы допросить свидетелей, собрать улики и назвать убийцу.

## Играть онлайн

**[▶ Открыть игру (GitHub Pages)](https://aysoobi.github.io/lecture-murder/)**

> Если ссылка не открывается сразу после публикации, подождите 1–2 минуты — GitHub Pages иногда обновляется с задержкой.

## Как играть

1. Нажмите **«Включить музыку»** (браузер требует клик для звука).
2. Прочитайте вступительный сюжет и пройдите короткое обучение.
3. Кликайте на персонажей в аудитории — до **4 допросов** каждого.
4. Читайте показания и выбирайте:
   - **(A) Верю** — если говорит правду
   - **(B) Не верю** — если лжёт
5. Соберите **9 улик** (верный выбор = +1 улика).
6. После **9 допросов** нажмите **«Сделать вывод»** и назовите убийцу.

### Штрафы за ошибку

- −1 улика  
- −10 секунд  
- +20% ужаса

## Запуск локально

Клонировать репозиторий и открыть `index.html` в браузере:

```bash
git clone https://github.com/aysoobi/lecture-murder.git
cd lecture-murder
open index.html
```

Или поднять локальный сервер:

```bash
python3 -m http.server 8080
# Открыть http://localhost:8080
```

## Деплой

Игра публикуется на **GitHub Pages** из ветки `main` (корень репозитория).

Ссылка для жюри: **https://aysoobi.github.io/lecture-murder/**

## Технологии

- Один HTML-файл (`index.html`) — без сборки
- Tailwind CSS (CDN)
- Canvas — пиксельные портреты NPC
- Web Audio API — фоновая музыка и звуковые эффекты
- DeepSeek API — генерация показаний (есть офлайн-запасные фразы)
